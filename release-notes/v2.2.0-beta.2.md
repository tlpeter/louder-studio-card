# Multiroom Audio Dashboard 2.2.0-beta.2

Documentation update: the README now contains real screenshots of Modern spectrum, Vintage hifi, Midnight studio and Retro spectrum, plus a screenshot and instructions for **Kleuren & uiterlijk**.

**Settings are in the dashboard card, directly below the title. HACS installs and updates the card.** Existing dashboards and legacy card configurations remain supported; replace the old resource once and keep only one loaded version.

HACS renders the README for the installed/selected version. Select this beta to see the illustrated guide in HACS. If needed, use Update information in the repository menu and reopen its details. Images use public HTTPS URLs; no GitHub account is needed to load them.

Audio and device-control behavior is unchanged from beta.1. Screenshots use synthetic players and demo audio, not a live Home Assistant installation. Physical speaker validation remains open in the compatibility issues.
