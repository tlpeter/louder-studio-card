# Multiroom Audio Dashboard 2.2.0-beta.2

The README now contains real screenshots of Modern spectrum, Vintage hifi, Midnight studio and Retro spectrum, plus a screenshot and instructions for **Kleuren & uiterlijk**.

**New visual speaker editor:** edit the dashboard, edit this card, then search/select your Home Assistant players under **Speakers beheren** and choose the **Hoofdspeler**. Save through Home Assistant. No YAML is needed for speaker selection. Existing amplifier EQ, mixer and diagnostics are preserved. Speakers must first exist in HA through an appropriate integration; HACS does not discover network devices.

**Settings are in the dashboard card, directly below the title. HACS installs and updates the card.** Existing dashboards and legacy card configurations remain supported; replace the old resource once and keep only one loaded version.

HACS renders the README for the installed/selected version. Select this beta to see the illustrated guide in HACS. If needed, use Update information in the repository menu and reopen its details. Images use public HTTPS URLs; no GitHub account is needed to load them.

Audio and device-service dispatch behavior is unchanged from beta.1. The editor changes dashboard configuration only and sends no device commands. Screenshots use synthetic players and demo audio, not a live Home Assistant installation. Physical speaker validation remains open in the compatibility issues.
