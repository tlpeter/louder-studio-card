# Multiroom Audio Dashboard 2.2.0-beta.1

The former Louder Studio prototype now has neutral branding and optional, capability-aware controls for Home Assistant media players. The original ESPHome equalizer setup and browser appearance preferences remain compatible.

Includes four adjustable styles, spectrum/analog source meters, EQ profiles for configured hardware, native source/sound mode, power, seek, shuffle and repeat when exposed by HA. Commands validate capabilities, targets and values; opening the card sends no device commands.

Repository setup includes dev/main, issue forms and labels, per-family hardware tracking, automated unit/browser tests, CodeQL, npm audit, Gitleaks and Dependabot.

**Beta limitation:** automated checks use synthetic data. Other speaker brands and the latest HA audio relay have not been physically verified. Extra vendor functions and grouping use HA's own player dialog where available. Live meters require Music Assistant/MilkDrop and show the mixed mono source before speaker DSP, not independent physical left/right output levels.

Install as a HACS custom **Dashboard** repository: `https://github.com/tlpeter/multiroom-audio-dashboard`. Enable beta versions to select this prerelease. Resource: `/hacsfiles/multiroom-audio-dashboard/louder-amplifier-card.js`. Keep only one resource registration. Both `custom:multiroom-audio-dashboard` and legacy `custom:louder-amplifier-card` configurations work. No HA restart is required for this frontend resource; reload the browser after installation.
