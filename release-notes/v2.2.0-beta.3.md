# Multiroom Audio Dashboard 2.2.0-beta.3

**Speakers beheren is now a prominent button at the top of the audio card.** Click it to open Home Assistant's native card editor, select speakers/main player and press Save. Dashboard edit mode and the hidden Edit button below the equalizer are no longer needed for supported panel/section layouts.

Opening the editor changes no dashboard data, EQ, volume or playback. Home Assistant handles Save/Cancel. The shortcut is available to administrators and identifies this card through its own HA ancestors/configuration; it refuses ambiguous, strategy-generated or YAML dashboard contexts rather than opening a different card.

Compatibility checks cover the HA 2026.10 numeric card paths and newer named paths with synthetic panel/section hosts. These are frontend protocol tests, not a live HA or physical speaker certification. The standard HA card editor remains available as a fallback.

Update through HACS and reload the browser. Keep only the HACS resource; a remaining old inline Louder resource can keep the old card active. Existing speaker, EQ and appearance configurations remain compatible.
